6. MOBILE AUTOPLAY FIX v2 (naya, is round ka asli fix):
   Pichli baar `video.muted = true` set kiya tha, lekin ek aur bug tha —
   code turant `video.currentTime = 0` set karne ki koshish karta tha,
   BINA ye check kiye ki video ka metadata load bhi hua hai ya nahi.
   Mobile Safari me agar metadata load nahi hua ho aur currentTime set
   karo, to woh line seedha ERROR throw kar deti hai — aur us error ki
   wajah se us error ke NEECHE wali `video.play()` line kabhi chalti hi
   nahi thi. Yahi asli reason tha ki autoplay silently fail ho raha tha.

   Ab:
   - currentTime sirf tabhi set hota hai jab video ka metadata pehle se
     ready ho (warna naya video element vaise bhi 0 par hi hota hai, to
     zaroorat nahi).
   - Agar play() phir bhi kisi wajah se fail ho (jaise data poora load
     nahi hua), to code khud video ke "canplay" event ka wait karta hai
     aur us waqt dobara play() try karta hai — matlab ab retry bhi hai.
