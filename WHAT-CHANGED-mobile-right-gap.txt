MOBILE "RIGHT GAP" FIX -- product page (after Price Filter round 2)
=====================================================================

ISSUE (jo aapne report kiya):
Mobile par product page ka right-side gap/padding gayab ho gaya tha,
aur ye "Shop by Price" price filter add karne ke turant baad shuru hua.

ROOT CAUSE (code check karke confirm kiya):
- `round2.diff` me jab product page par PriceQuickBrowseBar
  (Shop by Price chips, Add to Bag/Buy Now ke neeche) add kiya gaya,
  wo `ProductInfo` component ke andar gaya.
- `ProductInfo` ka root <div> ek CSS grid column hai
  (app/product/[slug]/product-detail.tsx me `lg:grid-cols-2` grid ka
  2nd column). Us div par `min-w-0` class missing thi.
- PriceQuickBrowseBar ka chip row `overflow-x-auto` + `whitespace-nowrap`
  use karta hai (scroll karne ke liye, wrap nahi hota). `min-w-0` ke
  bina, grid apne aap ko is row ke pure content ke barabar chauda kar
  leta hai -- yani poore page ko thoda zyada wide bana deta hai mobile par.
- globals.css me html/body par `overflow-x-clip` set hai, to ye extra
  width dikhta nahi (koi scrollbar nahi aata), bas silently clip ho
  jaata hai -- aur usi ke saath page ka right-side 16px gutter (jo
  `container-boutique` class deta hai) bhi clip ho jaata hai.
- Isi wajah se timing bilkul match karta hai: price filter (round 2)
  add hote hi ye problem shuru hui.
- Same left-side column (product gallery) me ye hi `min-w-0` pehle se
  hai -- isliye wahan koi issue nahi tha, sirf right column
  (ProductInfo) me missing thi.

FIX (1 line, 1 file):
File: app/product/[slug]/product-detail.tsx
`ProductInfo` function ke root div ko:
    <div className="flex flex-col gap-3">
se badal kar:
    <div className="min-w-0 flex flex-col gap-3">
kar diya (bilkul wahi pattern jo gallery column already use kar raha
tha). Isse grid column apne content ke andar hi horizontal scroll
allow karta hai, page ko wide nahi hone deta, aur right-side ka gap
wapas normal aa jaata hai.

Verified: `npm install` + `npm run typecheck` clean pass (koi TS/JSX
error nahi).
