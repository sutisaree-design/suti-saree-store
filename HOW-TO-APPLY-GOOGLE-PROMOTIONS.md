# Google Promotions feed (coupon toggle)

1. Run in Supabase SQL editor: supabase/migrations/20261015000000_coupon_google_promotions.sql
2. Deploy.
3. Admin -> Coupons -> turn ON "Google Promotions" for the coupons you want on Google.
4. Merchant Center -> Promotions -> Add promotions -> Add promotions from a file
   -> Enter a link: https://www.aruhihandlooms.com/api/promotions-feed -> Continue.
